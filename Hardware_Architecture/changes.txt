--- Change 1: early_exit_fsm.v --------------------------------------------------
File:     early_exit_fsm.v
Type:     Bug Fix
Status:   DONE

Problem:  CONFIDENCE_TH parameter default was 12, but hardware_architecture.md
          and the top-level instantiation both specify 8.
Fix:      Changed line 4: parameter CONFIDENCE_TH = 12  -->  8
Impact:   The early exit now triggers at 8 accumulated spikes instead of 12,
          matching the documented behavior (exit at T=4 to T=7).


--- Change 2: burst_redundancy.v -------------------------------------------------
File:     burst_redundancy.v
Type:     Bug Fix
Status:   DONE

Problem:  When a new pre_id arrived (different from last_pre_id), repeat_count
          was initialized to 3'd1 instead of 3'd0. This treated the first spike
          from any new source as "already seen once," making the filter
          slightly too aggressive.
Fix:      Changed line 23: repeat_count <= 3'd1  -->  3'd0
Impact:   The first spike from a new source is now correctly treated as a
          first occurrence, not a repeat.


--- Change 3: importance_monitor.v -----------------------------------------------
File:     importance_monitor.v
Type:     Bug Fix
Status:   DONE

Problem:  imp_keep was evaluated combinationally from the counter state BEFORE
          the current spike updated it. The very first spike from any pixel
          was always rejected (cnt=0 < THRESH=1), even though it's a real event.
Fix:      Replaced old logic:
            assign imp_keep = (cnt[pre_id] >= THRESH) ? 1'b1 : 1'b0;
          With prospective counter logic:
            wire [3:0] prospective_cnt = (spike_valid && cnt[pre_id] < 4'd15) ?
                                          cnt[pre_id] + 4'd1 : cnt[pre_id];
            assign imp_keep = (prospective_cnt >= THRESH) ? 1'b1 : 1'b0;
Impact:   The first spike from any pixel now passes through (prospective
          count = 0+1 = 1 >= THRESH=1).


--- Change 4: sparse_mac.v ------------------------------------------------------
File:     sparse_mac.v
Type:     Feature Addition
Status:   DONE

Problem:  The MAC accumulator (current_out) never reset between time steps or
          between neurons. It grew unbounded across the entire inference.
Fix:      Added new input port: acc_clear
          When acc_clear is asserted, current_out and read_req are zeroed.
          Priority: rst_n > acc_clear > sys_en (acc_clear checked before sys_en).
Impact:   The top-level controller can now reset the accumulator at neuron
          boundaries and time-step boundaries.

New port:
  input wire acc_clear  // Reset accumulator (at time-step / neuron boundaries)


--- Change 5: adaptive_lif.v ----------------------------------------------------
File:     adaptive_lif.v
Type:     Feature Addition
Status:   DONE

Problem:  The Python model uses BatchNorm before every LIF layer. BN normalizes
          activations so the threshold v_th=150 works correctly. The hardware
          had no way to incorporate the BN bias after folding BN into weights.
Fix:      Added new input port: bias_in [V_WIDTH-1:0]
          Integration equation changed from:
            v_integrated = v_mem - (v_mem >>> 4) + current_in
          To:
            v_integrated = v_mem - (v_mem >>> 4) + current_in + bias_in
Impact:   When export_weights_mem.py folds BN gamma/beta into the conv weights,
          the residual bias term can be fed in per-neuron.

New port:
  input wire signed [V_WIDTH-1:0] bias_in  // BN-folded bias (per-neuron)


--- Change 6: avg_pool.v --------------------------------------------------------
File:     avg_pool.v
Type:     NEW FILE
Status:   DONE

Problem:  The Python model has two AvgPool2d(kernel=2, stride=2) layers between
          conv stages. No pooling module existed in Verilog.
Created:  2×2 average pooling unit that:
          - Accepts 4 input values sequentially (2×2 window)
          - Accumulates into an (DATA_WIDTH+2)-bit register
          - Outputs average = sum >>> 2 (arithmetic right shift)
          - Has sys_en gating and data_valid handshake
          - pool_valid asserts for 1 cycle when output is ready

Ports:
  input  signed [DATA_WIDTH-1:0] data_in
  input  data_valid
  output signed [DATA_WIDTH-1:0] pool_out
  output pool_valid


--- Change 7: sparse_snn_top.v --------------------------------------------------
File:     sparse_snn_top.v
Type:     FULL REWRITE
Status:   DONE

Problem:  The old top-level was a mockup stub with:
          - pre_id hardwired to 10'b0  (every spike looked like pixel #0)
          - SRAM addr tied to 8'b0     (always read weight #0)
          - Only 1 LIF, 1 SRAM instance
          - Output routing was fake: {9'b0, lif_spike_out}
          - No address sequencing logic at all

Rewritten with:
  a) Layer FSM controller with states:
     IDLE -> LAYER1 -> POOL1 -> LAYER2 -> POOL2 -> LAYER3 -> LAYER4 -> IDLE
  b) 4 SRAM banks (conv1, conv2, fc1, fc2) with correct ADDR_WIDTH and MEM_FILE
  c) Address counters that step through synapse weights per neuron
  d) Gated read-enables (only active layer's SRAM draws power)
  e) Weight mux selecting the active SRAM output for the MAC
  f) MAC acc_clear asserted at neuron boundaries
  g) Pooling instances between conv stages
  h) Output spike routing via 10-class one-hot register driven by neuron_idx
  i) Closed-loop sys_enable feedback from Early Exit FSM

Parameters added:
  CONV1_ADDR_W, CONV2_ADDR_W, FC1_ADDR_W, FC2_ADDR_W (SRAM sizes)
  CONV1_NEURONS, CONV2_NEURONS, FC1_NEURONS, FC2_NEURONS
  CONV1_FANIN, CONV2_FANIN, FC1_FANIN, FC2_FANIN

Ports changed:
  Old: input [1:0] input_spike
  New: input spike_valid, input [9:0] spike_pre_id
  Added: output sys_enable

--- Change 9: adaptive_lif.v — External State Ports ----------------------
File:     adaptive_lif.v
Type:     Restructure
Status:   DONE

Problem:  The single LIF instance has one v_mem and one v_th register, but the
          pipeline needs to time-multiplex across hundreds of neurons per layer.
          Each neuron needs its own persistent membrane potential across timesteps.

Fix:
  Added external state load/store ports:
    input  wire                       state_load    // Load external state
    input  wire signed [V_WIDTH-1:0]  v_mem_load    // Membrane potential to load
    input  wire signed [V_WIDTH-1:0]  v_th_load     // Threshold to load
    output wire signed [V_WIDTH-1:0]  v_mem_out     // Updated membrane to save
    output wire signed [V_WIDTH-1:0]  v_th_out      // Updated threshold to save

  When state_load=1: internal v_mem/v_th loaded from external values.
  v_mem_out/v_th_out always reflect current internal state for writeback.

  Controller cycle: load state -> LIF computes -> read back -> next neuron


--- Change 10: sparse_snn_top.v — Inter-Layer Spike Buffers ---------------
File:     sparse_snn_top.v
Type:     Feature Addition (part of full rewrite)
Status:   DONE

Problem:  Layer 1 finishes computing spikes but they are not stored anywhere.
          Layer 2 has no way to know "which neurons fired in Layer 1."

Fix:
  Added register-file arrays:
    reg spike_buf_conv1 [0:25087]          // 32x28x28 bits (Conv1 output)
    reg spike_buf_pool1 [0:6271]           // 32x14x14 bits (after Pool1)
    reg spike_buf_conv2 [0:12543]          // 64x14x14 bits (Conv2 output)
    reg spike_buf_pool2 [0:3135]           // 64x7x7 bits   (after Pool2)
    reg spike_buf_fc1   [0:127]            // 128 bits       (FC1 output)

  FSM uses WRITE sub-states (S_L1_WRITE, S_L2_WRITE, S_L3_WRITE, S_L4_WRITE)
  to store spike_out from LIF into spike_buf[neuron_idx] after each neuron.
  Hidden layers read spike_in from previous layer's buffer via synapse_idx.


--- Change 11: sparse_snn_top.v — Per-Neuron State Arrays -----------------
File:     sparse_snn_top.v
Type:     Feature Addition (part of full rewrite)
Status:   DONE

Problem:  All neurons share one v_mem/v_th register. Membrane potential is
          overwritten every cycle — neurons have no persistent state.

Fix:
  Added per-layer state arrays (persist across timesteps):
    reg signed [V_WIDTH-1:0] vmem_conv1 [0:25087], vth_conv1 [0:25087]
    reg signed [V_WIDTH-1:0] vmem_conv2 [0:12543], vth_conv2 [0:12543]
    reg signed [V_WIDTH-1:0] vmem_fc1   [0:127],   vth_fc1   [0:127]
    reg signed [V_WIDTH-1:0] vmem_fc2   [0:9],     vth_fc2   [0:9]

  Controller loads vmem[neuron_idx]/vth[neuron_idx] into LIF via state_load,
  LIF computes, WRITE sub-state reads lif_vmem_out/lif_vth_out back to arrays.
  All state arrays initialized to v_mem=0, v_th=150 on reset.


--- Change 12: sparse_snn_top.v — Fix Pooling FSM -------------------------
File:     sparse_snn_top.v
Type:     Bug Fix (part of full rewrite)
Status:   DONE

Problem:  S_POOL1 and S_POOL2 states transitioned in a single clock cycle, but
          each pooling stage needs to iterate over all 2x2 windows:
            Pool1: 6,272 output values x 4 inputs each = 25,088 cycles
            Pool2: 3,136 output values x 4 inputs each = 12,544 cycles

Fix:
  Added pool_idx (window counter), pool_total, and pool_phase (0-3 counter).
  FSM stays in S_POOL1/S_POOL2, feeding 4 values from spike_buf into avg_pool.
  On pool_phase==3: writes pooled output to spike_buf_poolN, advances pool_idx.
  Transitions to next layer only after pool_idx reaches pool_total-1.

  Pooled spike determination: spike_buf_poolN[pool_idx] = (pool_out > 0)


--- Change 13: sparse_snn_top.v — Gatekeeper Only Layer 1 -----------------
File:     sparse_snn_top.v
Type:     Bug Fix (part of full rewrite)
Status:   DONE

Problem:  The gatekeeper (importance monitor + burst redundancy) is designed for
          raw event-camera input. It should NOT filter hidden layer activations.
          Previously, gate_keep drove the MAC for all layers.

Fix:
  Changed active_spike mux (combinational always block):
    S_LAYER1: active_spike = spike_valid & gate_keep    (gatekeeper-filtered)
    S_LAYER2: active_spike = spike_buf_pool1[synapse_idx]  (from buffer)
    S_LAYER3: active_spike = spike_buf_pool2[synapse_idx]  (from buffer)
    S_LAYER4: active_spike = spike_buf_fc1[synapse_idx]    (from buffer)
    default:  active_spike = 0

  Changed SRAM read-enables:
    conv1_re = mem_en_gate && (layer_state == S_LAYER1)   (gatekeeper-gated)
    conv2_re = sys_en      && (layer_state == S_LAYER2)   (always-on when sys_en)
    fc1_re   = sys_en      && (layer_state == S_LAYER3)   (always-on when sys_en)
    fc2_re   = sys_en      && (layer_state == S_LAYER4)   (always-on when sys_en)

  Also added mac_en_active mux:
    Layer 1: uses mac_en_gate (from gatekeeper)
    Hidden:  uses sys_en directly (bypass gatekeeper)
